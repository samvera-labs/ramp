# Ramp Component Library

Ramp (**R**eact **A**valon **M**edia **P**layer) is a ReactJS component library of interactive components created to display
audio/video resources in <a href="http://iiif.io/api/presentation/3.0/" target="_blank" rel="noopener noreferrer">IIIF Presentation 3.0</a>
manifests. These components are designed and built with reusability, customizability, and accessibility in mind.

## Installation Guide

### NPM (recommended)

For React applications using a build tool (Webpack, Vite, etc.).

#### Prerequisites

- Node.js ≥ 20.x
- `react` and `react-dom`

#### Steps

1. Install the component library:

```bash
yarn add @samvera/ramp
# or
npm install @samvera/ramp
```

From `v5.x`, VideoJS is included as a dependency and does **not** need to be installed separately.
For versions `< v5.x`, install the matching VideoJS version:
- `@samvera/ramp` version < `v3.1.3` → `video.js@7.21.3`
- `@samvera/ramp` version  between `v3.1.3` and `v4.0.2` → `video.js@8.10.0`

2. Import Ramp components and styles:

```js
import { IIIFPlayer, MediaPlayer, StructuredNavigation, Transcript } from '@samvera/ramp';

// Starter styles (includes VideoJS CSS for @samvera/ramp >= 5.0.0)
import '@samvera/ramp/dist/ramp.css';
```

**Important**: for `@samvera/ramp` version < 5.0.0 add `import 'video.js/dist/video-js.css'` before the start styles.

3. Use the imported Ramp components with the Manifest:

```jsx
const App = () => {
  const manifestUrl = 'https://some-manifest-url-here.json';

  return (
    <IIIFPlayer manifestUrl={manifestUrl}>
      <MediaPlayer enableFileDownload={false} />
      <StructuredNavigation />
    </IIIFPlayer>
  );
};

export default App;
```

### Vanilla JS (Standalone bundle)

For plain HTML/JS pages (Rails, PHP, etc.) with no React or related build tools, the standalone
<a href="https://preactjs.com/" target="_blank" rel="noopener noreferrer">Preact</a> bundle can be used to
build the page using Ramp's components.

#### Steps

1. Load the bundle and styles from <a href="https://unpkg.com/" target="_blank" rel="noopener noreferrer">unpkg</a> in the HTML:

```html
<link rel="stylesheet" href="https://unpkg.com/@samvera/ramp/dist/ramp.css" />
<script src="https://unpkg.com/@samvera/ramp/dist/ramp.standalone.umd.js"></script>
```

To pin to a specific version:

```html
<link rel="stylesheet" href="https://unpkg.com/@samvera/ramp@5.1.0/dist/ramp.css" />
<script src="https://unpkg.com/@samvera/ramp@5.1.0/dist/ramp.standalone.umd.js"></script>
```

Alternatively, download both files from the <a href="https://github.com/samvera-labs/ramp/releases" target="_blank" rel="noopener noreferrer">latest release</a>
and serve them locally.

```html
<link rel="stylesheet" href="ramp.css" />
<script src="ramp.standalone.umd.js"></script>
```

2. Render the player in the HTML page:

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <link rel="stylesheet" href="https://unpkg.com/@samvera/ramp/dist/ramp.css" />
</head>
<body>
  <script src="https://unpkg.com/@samvera/ramp/dist/ramp.standalone.umd.js"></script>
  <div id="root"></div>
  <script>
    const { IIIFPlayer, MediaPlayer, StructuredNavigation, React, ReactDOM } = RampIIIF;
    // Read Manifest URL from a query param 'iiif-content'
    const manifestUrl = new URLSearchParams(window.location.search).get('iiif-content');

    if (!manifestUrl) {
      alert('No manifest URL provided. Add ?iiif-content=<url> to the page URL.');
    } else {
      let parsed;
      try {
        parsed = new URL(manifestUrl);
      } catch {
        alert('Invalid URL in iiif-content parameter.');
        parsed = null;
      }

      if (parsed) {
        const root = document.getElementById('root');
        const playerTree = React.createElement(
          IIIFPlayer,
          { manifestUrl },
          React.createElement(
            'div', { className: 'iiif-player-demo' },
            React.createElement(MediaPlayer),
            React.createElement(StructuredNavigation)
          )
        );
        ReactDOM.createRoot(root).render(playerTree);
      }
    }
  </script>
</body>
</html>
```

Pass the manifest URL via the `iiif-content` query parameter: `your-page.html?iiif-content=https://your-manifest.json`

## Try It

The interactive playground below renders a fully functional Ramp player using the
<a href="https://samvera-labs.github.io/ramp/storybook-manifests/prod/lunchroom-manners.json" target="_blank" rel="noopener noreferrer">Lunchroom Manners</a>
IIIF Manifest.

The layout in this example uses `react-bootstrap` and `bootstrap` libraries to arrange components in a grid structure. Note that the published component
library does not include any Bootstrap-related styling — it ships with minimal styling via SASS.

The **top panel** displays a live-rendered UI that updates in real time as you edit the code.
The **bottom panel** is an editable code editor where you can modify component props, swap the manifest URL, or rearrange components.

{(() => {
  const code = `// Import components from library
  import {
  IIIFPlayer, MediaPlayer, StructuredNavigation,
  Transcript, MetadataDisplay, SupplementalFiles,
  Annotations,
} from '@samvera/ramp';
// Use react-bootstrap and bootstrap for layout in the example
import { Col, Row, Tab, Tabs } from 'react-bootstrap';
import 'bootstrap/dist/css/bootstrap.min.css';
// Import compiled styles from library
import '@samvera/ramp/dist/ramp.css';

export default function App() {
  const manifestUrl = 'https://samvera-labs.github.io/ramp/storybook-manifests/prod/lunchroom-manners.json';

  return (
    <IIIFPlayer manifestUrl={manifestUrl}>
      <MediaPlayer enableFileDownload={true} enablePlaybackRate={true} />
      <Row className="pt-3">
        <Col>
          <StructuredNavigation showAllSectionsButton={true} />
        </Col>
        <Col>
          <Tabs defaultActiveKey="details">
            <Tab eventKey="details" title="Details" className="border border-top-0">
              <MetadataDisplay showHeading={false} />
            </Tab>
            <Tab eventKey="transcripts" title="Transcripts" className="border border-top-0">
              <Transcript
                playerID="iiif-media-player"
                manifestUrl={manifestUrl}
                showMoreSettings={{ enableShowMore: true }}
              />
            </Tab>
            <Tab eventKey="files" title="Files" className="border border-top-0">
              <SupplementalFiles showHeading={false} />
            </Tab>
            <Tab eventKey="annotations" title="Annotations" className="border border-top-0">
              <Annotations showHeading={false} showMoreSettings={{ enableShowMore: true }} />
            </Tab>
          </Tabs>
        </Col>
      </Row>
    </IIIFPlayer>
  );
}`;

  const Container = (props) => (
    <div className="sb-unstyled" style={{ borderRadius: '8px', overflow: 'hidden', border: '1px solid #e0e0e0' }}>
      <div style={{ padding: '16px', minHeight: '600px' }}>
        {props.preview}
      </div>
      <div style={{ height: '400px', overflow: 'auto', resize: 'vertical', borderTop: '1px solid #e0e0e0' }}>
        {props.editor}
      </div>
    </div>
  );

  return (
    <Playground
      availableImports={{
        '@samvera/ramp': RampLibrary,
        'react-bootstrap': ReactBootstrap,
        '@samvera/ramp/dist/ramp.css': {},
        'bootstrap/dist/css/bootstrap.min.css': {},
      }}
      code={code}
      Container={Container}
      defaultEditorOptions={{
        minimap: { enabled: false },
        lineNumbers: 'on',
        fontSize: '13px',
        scrollBeyondLastLine: false,
      }}
      modifyEditor={(monaco, editor) => {
        monaco.editor.setTheme('vs-dark');
      }}
    />
  );
})()}
