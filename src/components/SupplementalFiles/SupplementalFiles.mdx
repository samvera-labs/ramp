# SupplementalFiles

`SupplementalFiles` reads the `rendering` property at both the Manifest level and Canvas level and lists the files as downloadable links.
It reads data from React Contexts and must be wrapped by [`IIIFPlayer`](?path=/docs/components-iiifplayer--docs).

## Usage

```js
import { SupplementalFiles } from '@samvera/ramp';
```
