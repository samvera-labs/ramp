# Transcript

Transcript component displays transcript data in a given IIIF Manifest via `manifestUrl` or `transcripts`, when used along with a media-player
linked via `playerID` prop it synchronizes scroll position with media playback for timed-text transcript formats (WebVTT, SRT).
__Either `manifestUrl` or `transcripts` is REQUIRED. If both props are given then `transcripts` takes *precedence* over `manifestUrl`__.

This component can be used **decoupled from the Context providers** and therefore requires explicit props rather than reading from shared state.
`playerID` prop and one of `manifestUrl`/`transcripts` props are _required_ to be defined when using the component in this manner.

When using this component with a different non-Ramp media player, the player should have a `data-canvasindex` attribute set with a zero-indexed number,
which points to the current Canvas rendered from the Manifest in the player.

## Usage

```js
import { Transcript } from '@samvera/ramp';
```
