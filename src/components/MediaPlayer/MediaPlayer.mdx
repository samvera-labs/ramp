# MediaPlayer

MediaPlayer component provides a player that facilitates both audio and video media files in a IIIF Manifest. 
It encapsulates a [VideoJS](https://videojs.com/), which is an HTML5 player framework. `MediaPlayer` component fetches data from central state management system using Context providers. 
Therefore this component must *always* be wrapped by `IIIFPlayer` component.

## Usage

```js
import { IIIFPlayer, MediaPlayer } from '@samvera/ramp';
```
